# Roadmap

## Phase 1 — Documentation

- Finalize project documentation.
- Remove duplicated information.
- Keep each document focused on a single topic.

## Phase 2 — Code Cleanup

- Review all patches.
- Remove temporary debug code.
- Improve comments where appropriate.
- Verify that Android-specific changes remain isolated.
- Keep patches synchronized with the working source.

## Phase 3 — Build and Testing

- Document a reproducible build procedure.
- Add startup and restart scripts.
- Expand testing with additional CCID devices.
- Improve troubleshooting documentation.

## Phase 4 — Upstream Readiness

- Review patches for upstream quality.
- Minimize platform-specific changes.
- Prepare documentation suitable for external reviewers.
- Evaluate submission of Android support to upstream projects.
