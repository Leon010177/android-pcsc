# Android PC/SC for Termux

This project contains patches, scripts and documentation for running PC/SC, libccid and OpenSC on Android using Termux and termux-usb.

Current status:
- Working USB transport using termux-usb
- Working pcsc-lite
- Working libccid
- Working OpenSC
- Tested with YubiKey PIV

The goal is to provide a clean, reproducible and well documented solution that can be used on other Android devices.
